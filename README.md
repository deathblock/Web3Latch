# Web3Latch

Web3Latch enables real-time cross-chain data synchronization and smart contract-based transaction processing via a decentralized gateway.

Web3Latch is built to be simple and practical, focusing on doing one thing well.

**Why Web3Latch?**

- Web3Latch enables real-time cross-chain data
- synchronization and smart contract-based transaction
- processing via a decentralized gateway

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/Web3Latch.git`
2. `cd Web3Latch`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure Web3Latch, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
